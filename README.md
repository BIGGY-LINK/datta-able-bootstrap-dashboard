## FCWM Student Complaint System

This repository also includes a PHP/MySQL support-ticket application for the Federal College of Wildlife Management. It reuses the supplied Datta Able dashboard assets and has separate student, administrator, and department workspaces.

### Run with XAMPP

1. Copy the project folder into `C:\xampp\htdocs\` if it is not already there.
2. Start **Apache** and **MySQL** in the XAMPP Control Panel.
3. Open `http://localhost/xampp/datta-able-bootstrap-dashboard/` in your browser (adjust the URL to match the folder name and location).
4. On first visit, complete the setup page to create the first administrator and enter the college's departments. The application creates the `fcwm_student_support` database and its tables automatically.
5. Sign in as the administrator, then add a department and its staff account from **Departments**. Students can create their own accounts from the sign-in page.

The default XAMPP connection uses MySQL host `127.0.0.1`, port `3306`, database `fcwm_student_support`, user `root`, and a blank password. Override these defaults with the `FCWM_DB_HOST`, `FCWM_DB_PORT`, `FCWM_DB_NAME`, `FCWM_DB_USER`, and `FCWM_DB_PASS` environment variables if needed. The MySQL account must have permission to create the database and tables.

Students submit categorized tickets and track them from their account or using their ticket reference and registered email address. Administrators route tickets to departments; department accounts can only view and update tickets assigned to their own department.

The public welcome page includes locally hosted campus and classroom photos from [Unsplash](https://images.unsplash.com/photo-1562774053-701939374585) and [Unsplash](https://images.unsplash.com/photo-1509062522246-3755977927d7). Both are used under the [Unsplash License](https://unsplash.com/license).

#### Application requirements

- PHP 8.1+ with PDO MySQL enabled
- MySQL or MariaDB (XAMPP defaults are supported)
- Apache with PHP enabled

## Getting Started

1. Clone from Github

```
git clone https://github.com/codedthemes/datta-able-bootstrap-dashboard.git
```

2. Install packages

```
 npm i
```

3. Run project

```
gulp
```
